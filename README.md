# Python-unit-project (Hayyak)

Saudi-dialect voice translator built with Streamlit.

## Setup (Windows, run once)

```
git clone https://github.com/HassanAlsuwaiq/Python-unit-project.git
cd Python-unit-project
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```
.venv\Scripts\activate
streamlit run app.py
```

The `.env` file with the API keys is already included.
